# EPIC ШАШКИ

Шашки для Android: 10 вариантов правил (турецкие, русские, международные 10×10, английские/чекерс,
бразильские, пул, итальянские, канадские 12×12, испанские, чешские) + режим «поддавки» для любого из них.
Игра против ИИ (5 уровней), вдвоём на одном телефоне и «Битва ИИ». Особый **EPIC BADASS MODE** —
аниме-эффекты на каждом ходу и хвастовство; классический режим — спокойная деревянная доска.
Новый режим **«Валькирии доски» (盤上戦姫)** — тактическая аниме-RPG на доске 8×8 с 24 героинями.

## Скачать

APK: [`release/EpicCheckers.apk`](release/EpicCheckers.apk) — версия 1.2.0 (≈10 МБ, Android 7.0+).
При установке Android попросит разрешить установку из неизвестного источника.
Ставится поверх предыдущей версии (тот же ключ подписи).

## Что нового в 1.2.0 — «Валькирии доски»

- **Новый режим** — большая плитка «Валькирии доски» в главном меню (盤上戦姫, бейдж «Новое!»). Тактическая
  аниме-RPG на доске 8×8: каждая шашка — героиня с ролью, стихией, навыком и Вспышкой (ультой); ходы по
  диагонали, **прыжок-удар с цепочками** и пробуждение в «дамку» на заднем ряду противника; 8 стихий и 8 реакций.
- **24 коллекционные героини** с артом и японской озвучкой (Эпические и выше), **Призыв** за внутриигровые
  кристаллы (без доната), созвездия C1–C6, уровни 1–30, свитки опыта, отряд из 6.
- **Кампания** из 3 глав (27 этапов с боссами), **Тренировка** и **Дуэль** вдвоём на одном телефоне
  (драфт героинь, экран «Передай телефон»). Авто-бой и скорость ×2, пропуск роликов тапом.
- Старт: 6 героинь в отряде, 3 200 ✦ (20 призывов) и 5 свитков опыта. Незаконченный бой сохраняется
  и предлагается продолжить, награды записываются сразу.
- Настройки режима: озвучка и её громкость, кинематика Вспышек (полная / короткая / только в первый раз),
  цифры урона. Классические шашки не изменились.

## Что нового в 1.1.0

- **Оптимизация:** лимит 60 кадров/с (на экранах 90/120 Гц раньше было вдвое больше работы), 30 кадров/с в простое,
  пониженное разрешение рендера, фон обновляется реже, без дорогого CSS-размытия поверх игры;
  качество «Авто» само снижается, если телефон не успевает; режим «Экономия батареи».
- **Тексты и анимации дольше:** каждая надпись держится столько, сколько нужно, чтобы её прочитать
  (зависит от длины), кинематика неторопливее. Тап по экрану по-прежнему пропускает ролик.
- **Индивидуальные настройки:** имя игрока и цвет энергии; пресеты «Максимум / Баланс / Спокойно / Экономия батареи»;
  каждый эффект отдельно (тряска, вспышки, замедление, камера, врезки, звукоподражания, хвастовство, баннеры,
  счётчик комбо, частицы, ауры, фон, VS-заставка); скорость анимаций 0.5×–2×; время показа текста 1×–3×;
  короткие ролики соперника; темп ИИ; вибрация выкл/слабая/сильная.
- Исправления по итогам QA: наслоение надписей, засветка кульминаций, формулировки, ничья с ИИ,
  автосохранение партии («Продолжить партию»), ИИ не сводит партии к ранним ничьим. Список — в
  [`docs/QA-FINDINGS.md`](docs/QA-FINDINGS.md).

## Сборка

Нужны Node 22, JDK 17+, а также `aapt`, `dalvik-exchange`, `zipalign`, `apksigner` (пакеты Debian/Ubuntu)
и `android.jar` API 34 по пути `/opt/android-jars/android-34-reginer.jar` (см. `tools/build-apk.sh`).

```bash
npm ci
npm test            # юнит-тесты движка, ИИ, рендера, эффектов, UI, звука и RPG-модулей
npm run build       # web-бандл (dist/www) + APK (dist/EpicCheckers.apk)
npm run e2e:quick   # сквозные тесты в headless Chromium
```

Ключ подписи `android/keystore/epic-checkers.jks` (пароль `epicbadass`) лежит в репозитории намеренно —
это хобби-проект, так обновления ставятся поверх старой версии.

«Валькирии доски» — [`docs/RPG-ARCHITECTURE.md`](docs/RPG-ARCHITECTURE.md) и дизайн-документ
